Jujhar Daily Sheet: installable app (PWA)

1. Upload EVERYTHING in this folder (index.html, sw.js, manifest.webmanifest and the 4 icons)
   to an HTTPS static website host, for example:
   - Netlify: app.netlify.com/drop, drag this folder onto the page.
   - Cloudflare Pages or GitHub Pages also work.
2. Open the site address on the phone:
   - Android (Chrome): menu > Install app (or "Add to Home screen").
   - iPhone (Safari): Share > Add to Home Screen.
   - PC (Chrome/Edge): the install icon at the right of the address bar.
3. After the first visit it works without internet.

Updating: upload the new files over the old ones. Phones pick up the new version
the next time the app is opened with internet (open it twice to see it).

Moving data from the old file version: in the old copy use "Save progress" (for the day in
progress) and Vehicle list > "Back up to Excel"; in the app use "Open progress" and
"Restore from Excel". Saved days stay where they were made. Load yesterday's saved
sheet to carry the opening balance.
